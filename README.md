# Essaara Platform

Purely Ayurvedic • Naturally Divine

Welcome to the **Essaara Platform** repository. This is a full-stack e-commerce storefront for premium Ayurvedic bath, body, and home fragrances.

## Architecture
- **Frontend**: React, Vite, Tailwind CSS, React Router (Configured for Vercel)
- **Backend**: Node.js, Express, MongoDB (Configured for Render)
- **Image Storage**: Cloudinary integration for product images

## Getting Started

### Frontend
1. Navigate to `essaara-platform/frontend`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`

### Backend
1. Navigate to `essaara-platform/backend`
2. Install dependencies: `npm install`
3. Configure your `.env` file (see `.env.example`)
4. Start the server: `node server.js`

## Deployment
- The frontend is ready to be deployed on **Vercel**.
- The backend is ready to be deployed on **Render**.

Enjoy the Essaara experience!
